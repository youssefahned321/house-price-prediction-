# 🏠 House Price Prediction

## 📌 Project Overview

This project focuses on predicting house prices using machine learning regression techniques. It explores housing features and investigates how they relate to property prices.

## 🎯 Objectives

- Explore and understand housing data.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify important features affecting house prices.
- Train machine learning regression models.
- Evaluate model performance using regression metrics.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset Features

The dataset may include features such as:

- OverallQual
- GrLivArea
- GarageCars
- TotalBsmtSF
- YearBuilt
- FullBath
- BedroomAbvGr
- LotArea
- SalePrice (target variable)

## ⚙️ Project Workflow

1. Data loading and inspection.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis.
4. Feature selection and preparation.
5. Model training and prediction.
6. Model evaluation and result visualization.

## 📈 Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🚀 How to Run

1. Clone the repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Open the Jupyter Notebook.
4. Run the cells to explore the data, train the model, and evaluate predictions.
